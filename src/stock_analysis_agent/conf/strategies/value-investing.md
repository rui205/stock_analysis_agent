# 价值投资策略 v2

## 核心原则

1. **估值合理**:PE-TTM 不高于近 5 年中位数 + 20%,PB 不高于行业均值 + 30%。
2. **盈利质量**:近 3 年 ROE 均值 ≥ 10%,毛利率 ≥ 30%。
3. **财务稳健**:资产负债率 ≤ 60%,经营性现金流 ≥ 归母净利润(无纸面富贵)。
4. **股东回报**:近 3 年连续派息,股息率 ≥ 2%(A 股)/ ≥ 4%(港股);或近 3 年有持续**注销式**回购(注销金额视同分红,回购用于股权激励 / 转库存股的不得计入)。
5. **回避烧钱**:不投未盈利公司、不投近 3 年累计融资 > 市值 30% 的标的。

## 加分项

- 行业龙头(收入或利润 Top 3)
- 管理层增持 / 回购(仅作管理层信心信号,非注销式回购不计入股东回报)
- 估值分位 < 30%(明显低估)

## 一票否决

- 资产负债率 > 80%
- 近 12 个月被监管立案 / 问询未结案
- 商誉 / 总资产 > 30%
