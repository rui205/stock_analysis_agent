# 质量成长策略 v1

## 核心原则

1. **盈利质量**:近 3 年 ROE 均值 ≥ 15%,毛利率 ≥ 40% 且逐年不降。
2. **成长性**:近 3 年营收/净利 CAGR ≥ 15%,无单年负增长。
3. **现金流**:经营现金流 / 归母净利润 ≥ 1.0(盈利是真金白银)。
4. **估值**:PEG ≤ 1.5,PE-TTM 不高于行业均值 + 20%。

## 加分项

- 行业龙头(收入或利润 Top 3)
- 研发投入占比 ≥ 5%

## 一票否决

- 近 3 年累计股权融资 > 市值 20%
- 商誉 / 净资产 > 20%
